# HANDOFF — встав це в новий чат (коротка пам'ять проєкту)

**Проєкт:** `petroju/pult` → PWA «Zhyva Voda» (https://petroju.github.io/pult/). Один файл `index.html` (~790 КБ, vanilla JS, без збірки), `sw.js` (кеш — піднімати `VERSION` у кожному релізі), `hw.json`, `inbox.json`, `ua-words.json`. Інтерфейс англійською, зі мною говорити українською. Гілка для роботи: `claude/wizardly-lovelace-cmjozp`. PR не створювати без прохання.

**Як влаштований код (`index.html`):**
- Стан: `S` налаштування, `D` сьогоднішній день (`day-YYYY-MM-DD`), `HIST` дні, `G` цілі/все довготривале (`goals`), `A` теми повторення (`rev-nmt`), `BD` борд. Збереження: `saveDay()`, `saveGoals()`, `saveSettings()`, `saveBoard()`, `saveArea(a)`. Усе синхронізується через gist + Google Drive.
- Екрани: функції `vXxx()` повертають HTML; маршрути в `render()` / `TAB_OF`; дії — `data-act="..."` → великий `switch (act)` у блоці `events`.
- Бали: `dayPts(k)` (⭐). Ліга бере саме їх.
- Тест: `python3 -m http.server` + Playwright (Pixel 7), годинник `page.clock`.
