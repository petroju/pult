# HANDOFF — встав це в новий чат (коротка пам'ять проєкту)

**Проєкт:** `petroju/pult` → PWA «Zhyva Voda» (https://petroju.github.io/pult/). Один файл `index.html` (~860 КБ, vanilla JS, без збірки), `sw.js` (кеш — піднімати `VERSION` у кожному релізі, зараз v56), `hw.json`, `inbox.json`, `ua-words.json`. Інтерфейс англійською, зі мною говорити українською. Гілка для роботи: `claude/wizardly-lovelace-cmjozp` (після злиття PR — перезапускати від `main`). PR створювати лише коли я прошу.

**Як влаштований код (`index.html`):**
- Стан: `S` налаштування, `D` сьогоднішній день (`day-YYYY-MM-DD`), `HIST` дні, `G` усе довготривале (`goals`), `A` теми повторення (`rev-nmt`), `BD` борд. Збереження: `saveDay()`, `saveGoals()`, `saveSettings()`, `saveBoard()`, `saveArea(a)`. Синхронізація: gist + Google Drive → Obsidian.
- Екрани: функції `vXxx()` повертають HTML; маршрути в `render()` / `TAB_OF`; дії — `data-act="..."` → великий `switch (act)` у блоці `events`.
- Бали: `dayPts(k)`. Рядок чисел за день для бейджів і викликів: `mvDay(k)` / `mv(k)`; за період — `cntRange(metric, from, to)`; за весь час — `gameStats()`.
- Тест: `python3 -m http.server` + Playwright (Pixel 7), годинник `page.clock`.

**Мої відповіді й побажання:**
- Control boards (у коді `fields`) = дошки по сферах; там тепер і навички. Домашку майже не роблю → спростити.
- Пуш-сповіщення не потрібні. Сезон ліги = 1 тиждень. Боти майже ідеальні, різні, з іменами.
- Англійська рахується в чеклістах (1 на день, пропущений день не надолужити), слова — окремо.
- Програма має лишатися простою: відкрив → зробив, що каже банер → поставив галочку.
- Усе, що пишу, йде в Obsidian; я додам Obsidian і книги — Claude має проаналізувати й поглибити збірку принципів (особливо Сейсембаєв: зараз вона зібрана з назв розділів його книги в моїх нотатках і з того, що знайшлось в інтернеті; сайти з конспектами лекцій були недоступні).
