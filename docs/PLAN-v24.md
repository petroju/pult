# Zhyva Voda v24 — план апгрейду (сценарій для роботи з Fable)

> Статус: **v24.0 і v24.1 зроблено 15.11.2026** — ліга, банер «зараз», ранкова місія, повторення ZNOHUB і НМТ порціями, теми, бейджі, виклики на час, навички, збірка принципів, детальні алгоритми, англійська в чеклістах, інструкція. Що лишилось — у `docs/HANDOFF.md` (читати першим).
> Програма: `index.html` (одна сторінка, ~730 КБ), вкладки: **Day · Work · Board · Dreams · Progress** (+ NMT).
> Мова інтерфейсу — англійська (як зараз), цей план — українською.

## 0. Як працюємо з Fable

1. **Одна фіча → один коміт → перевірка на телефоні.** Не робимо все за раз.
2. **Дані не губимо.** Будь-яка нова структура в `Store` — з міграцією старих даних (спершу експорт-бекап).
3. Кожен етап = нова версія (v24.0, v24.1 …) + рядок у README.
4. Порядок етапів — розділ 13. Відкриті питання — розділ 14 (відповісти перед стартом).

## 1. Ядро: XP («досвід») — усе, що я роблю, рахується

Зараз прогрес цілі = одне число (наприклад, слова для англійської). Треба, щоб **кожна дія давала XP** і рухала ціль.

На чому це базується (дослідження з геймифікації/психології звичок):
- **Goal-gradient effect** — що ближче видно фініш, то швидше людина рухається → показуємо «до наступного рівня 40 XP».
- **Endowed progress** — коли прогрес уже не нульовий, люди частіше доходять → нова ціль стартує з 5–10 %.
- **Loss aversion** — втратити боляче сильніше, ніж отримати → ліги з вильотом, серія (streak), яку шкода зламати.
- **Variable reward** — непередбачувана нагорода тримає інтерес → іноді «x2 XP», випадковий бонус-квест.
- **Implementation intentions** («коли X — роблю Y») — найсильніший доведений спосіб виконувати плани → інструкція в розділі 12.
- **Fogg: B = Motivation × Ability × Prompt** — дія відбувається, коли є підказка → банери (розділ 4).

**Таблиця XP (стартова, підкрутимо):**

| Дія | XP |
|---|---|
| Урок англійської відвідав / блок 2 год зробив | +30 / +40 |
| Нове слово/фраза вивчена (4 вживання) | +3 |
| Тема НМТ: позначив етап (вебінар / тест / перевірка) | +10 за етап |
| Тема НМТ пройдена повністю (9/10) | +50 |
| Повторення вчасно / прострочене | +15 / +8 |
| Тест ZNOHUB | +5 за тест |
| Домашка від Claude | +10 |
| 10 сторінок книги | +10 |
| Тренування / біг / футбол | +20 |
| Біблія, кайдзен, вечірній огляд | +10 кожне |
| Опублікований рілс / відео | +25 |
| Картка з борду зроблена | +5 × її бали |

- **Комбо:** 3 різні сфери за день → ×1.2; «повний день» → ×1.5.
- **Рівні:** загальний рівень (Lv 1–100) + **рівень кожної цілі** («English Lv 7», «Math Lv 4»).
- **Прогрес цілі = зважена сума** (наприклад, English: уроки 40 % + слова 25 % + фрази 15 % + помилки/виміри 20 %). Ваги — в налаштуваннях цілі.

## 2. Ліги з ботами (дисципліна через змагання)

- **20 ліг (як зроблено):** Bronze IV…I → Silver IV…I → Gold IV…I → Platinum IV…I → Diamond IV…I.
- **Сезон = тиждень** (пн 00:00 – нд 23:59). У групі я + 19 ботів.
- **Топ-5 — підвищення, низ-5 — пониження**, решта лишаються.
- **Боти чесні, але живі:** кожен має «характер» (стабільний, ривок у неділю, лінивий у середу…), XP набирає протягом дня. Сила ботів = **мій середній тиждень за 4 тижні × (0.8…1.3)** залежно від ліги → у вищих лігах треба працювати більше, ніж зазвичай.
- **Суперник тижня (rival):** один бот трохи сильніший за мене, видно на Day: «Max: 840 XP · ти: 790 · ще 50 до обгону».
- Окремі **рейтинги-характеристики** (як у RPG): Сила (спорт), Розум (НМТ), Мова (англ.), Дух (віра), Творчість (контент), Дисципліна (вчасні справи). Кожна — радар-діаграма на Progress.
- Нагорода за лігу: бейдж, кольорова рамка, рядок в історії сезонів.
- **Захист від вигорання:** 1 «заморозка серії» на тиждень (неділя-відпочинок не ламає streak).

## 3. Цілі — красивіше і цікавіше

- Картка цілі: кільце прогресу + **рівень + XP-смуга** + «наступна віха» (milestone) + «за 7 днів +X %».
- **Бос місяця:** пробний НМТ / вимірювання англійської = «бос». Перемога (≥ цілі) → великий бонус XP і бейдж.
- **Віхи-нагороди:** 25 / 50 / 75 / 100 % — анімація + запис у «Хроніку».
- Ціль показує **звідки прийшов прогрес** (уроки, слова, теми…) — щоб було видно, що галочки працюють.

## 4. Банери «Зроби це зараз» + ранкова місія

- **Ранок:** перше відкриття до 11:00 → **повноекранна місія** (mission + 6 афірмацій). Кнопка «Прочитав» активна через 15 с. Поки не прочитав — Day затемнений.
- **Банери на Day зверху** (червоні/жовті), напр.:
  - «❗ Не зроблено: Anki, вечірні помилки, 2 повторення НМТ — **Зроби зараз**» (кнопка відкриває потрібну сторінку).
  - «⏰ Урок ZNOHUB о 18:00 через 20 хв».
  - «📉 Rival тебе обганяє на 60 XP».
- Ескалація: 1-й раз жовтий → після часу дедлайну червоний → увечері в «Evening review» як «пропущено».
- Сповіщення на телефоні: PWA вміє локальні нотифікації, **поки програма відкрита/у фоні**; надійні пуші вимагають сервер — **питання до обговорення** (можна через Google Apps Script або календар).

## 5. Kaizen / Scrum / Evening review → одразу в картки

- Внизу кожного запису кнопка **«→ Claude»**: копіює текст + промпт. Claude відповідає JSON-ом у `inbox.json` → картки з'являються на Board (механізм `inbox.json` вже є).
- **Локальний розбір без Claude:** рядки, що починаються з `→`, `-[ ]` або `todo:`, автоматично стають картками «Сьогодні/Завтра».
- Підсумок вечора: «3 нові картки створено» + XP.

## 6. Board — виправити додавання в Day

- **Баг:** не виходить додати картку в Day / створити картку. Fable: відтворити (функції `moveCard`, `cardRow`, `vToday` у `index.html`), знайти причину, полагодити.
- Додати: кнопка «+» в кожній колонці, свайп картки вправо = «Сьогодні», довге натискання = «Завтра».

## 7. Книги — нормальний вигляд

- На Day блок **«Зараз читаю»**: обкладинка (Open Library Covers за назвою/ISBN), назва, автор, **сторінка 134 / 320**, смуга прогресу, темп (стор./день), **прогноз дати завершення**.
- Кнопки швидкого вводу: **+5 / +10 / +20 стор.** або «я на сторінці …».
- Полиця: «Читаю · Далі · Прочитано» з обкладинками, оцінка ★, 3 головні думки + цитати з книги.
- Трекер-серія лишається, але стає другорядною.

## 8. НМТ + ZNOHUB

- **Мапа тем ZNOHUB ↔ теми НМТ** у програмі: теми ZNOHUB названі інакше → таблиця відповідностей; пройдений урок ZNOHUB = етап теми НМТ.
- Повторення тем ZNOHUB у тому ж ритмі 1 · 3 · 7 · 21 · 51 днів.
- **Щонеділі аналіз:** Claude читає `data.json`, дивиться слабкі теми + нові уроки ZNOHUB → додає в `hw.json`/`inbox.json` повторення і нове.
- **Прострочені повторення (зараз ~19 днів):** «План наздоганяння» — розкласти борг на 7–10 днів, максимум 3 на день, спершу найважливіші теми для НМТ. Окремий XP-бонус «Борг закрито».

## 9. Домашка

Зробити простіше: один список на день з дедлайном, предметом і XP; прострочена — у банер. Кнопка «Здав» → Claude перевіряє через `hw.json`. (Обговорити, що саме не подобається зараз.)

## 10. YouTube / контент — переробити

Зараз виглядає негарно. Пропозиція:
- Окремий екран **Content**: конвеєр **Ідея → Сценарій → Зйомка → Монтаж → Опубліковано** (міні-канбан).
- Банк ідей (швидке додавання з будь-якого місця), «день пакетної зйомки» (3 рілси за раз — це вже є в плані).
- Лічильник: опубліковано X / 100, ціль на тиждень 3, XP за кожен етап.
- Окремо **«споживання»**: навчальні відео НМТ — через вбудований плеєр із «Watched» (є); розважальний YouTube — таймер-обмежувач.

## 11. Рутина

- **Ранкова і вечірня рутина** як таймлайн-чекліст (підйом → афірмації → душ+зарядка → Біблія 45 хв → кайдзен → сніданок …) з часом і XP.
- Режими дня A/B/C вже є — рутина підлаштовується під режим.
- «Control boards», «Face» — **уточнити** (див. питання).

## 12. Мої ідеї для продуктивності

1. **Топ-3 дня (MIT):** зранку вибираю 3 головні справи; поки вони не зроблені — інше сіре.
2. **Deep-work контейнери 45 хв** (таймер уже є) → XP за кожен + статистика «годин фокусу за тиждень».
3. **«Якщо — то» плани** до кожної цілі (наприклад, «якщо відкрив YouTube після 21:00 — закриваю і читаю 10 стор.»).
4. **Телефон-комендантська година:** після 22:30 програма показує лише вечірній огляд і сон.
5. **Щотижневий звіт** (неділя): XP, ліга, найкраща/найгірша сфера, що змінити → одразу в Sunday Scrum.
6. **Досягнення (бейджі):** «7 днів без пропуску Anki», «10 тем НМТ на 9/10», «перша книга за місяць»…
7. **Енергія → вибір задач:** енергія низька — програма пропонує легкі картки, висока — складні.
8. **Підзвітність Claude:** раз на тиждень Claude пише чесний коментар у `inbox.json` («ось де ти злив години»).

## 15. Інструкція: коли що робити (чернетка, оновимо після v24)

**🌅 Прокинувся**
→ Відкрий програму → прочитай **місію** (повноекранно) → натисни «Прочитав».
→ **Day**: вибери режим дня (A/B/C) і енергію → вибери **Топ-3** справи.
→ Пройди **ранкову рутину** (галочки по черзі). Біблія → галочка Faith.

**📚 Навчання**
→ Сідаєш за НМТ → **NMT → тема дня** → таймер кроків → після кожного етапу (вебінар/тест/перевірка) — **галочка** (+XP).
→ Пройшов урок/тести ZNOHUB → **NMT → ZNOHUB** → введи кількість тестів.
→ Повторення → **NMT → «Повторити сьогодні»** (спершу прострочені з плану наздоганяння).
→ Помилка в тесті → одразу в **швидкий журнал помилок** (→ Anki).
→ Англійська: урок/блок 2 год → **Work → English → чекліст дня** → таймер блоку; нові слова → **Words Inbox**.

**📖 Прочитав книгу**
→ **Day → «Зараз читаю» → +10 стор.** (або введи сторінку). Думка/цитата → «Нотатки книги».

**🏃 Тренування / біг / футбол**
→ **Work → Health** → галочка.

**📱 Зняв / виклав рілс**
→ **Content** → пересунь на «Опубліковано».

**💡 Прийшла ідея / справа**
→ **Board → «+»** (або в Kaizen рядок з `→`) → «Сьогодні» чи «Завтра».

**🔔 Бачиш червоний банер**
→ Натисни **«Зроби зараз»** — він веде туди, де треба. Не закривай, поки не зробив.

**🌙 Вечір**
→ **Evening review**: що вдалось, що ні, ефективність → **«→ Claude»** → картки на завтра.
→ Глянь **лігу**: де ти і скільки до rival. → Сон.

**🗓 Неділя**
→ **Sunday Scrum (7 кроків)** + тижневий звіт → Claude робить аналіз НМТ/ZNOHUB і додає нове на тиждень.
→ Підсумок сезону ліги: підвищення / пониження.
